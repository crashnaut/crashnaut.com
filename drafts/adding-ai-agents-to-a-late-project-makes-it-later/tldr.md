---
title: "Adding AI Agents to a Late Project Makes It Later"
slug: adding-ai-agents-to-a-late-project-makes-it-later
---

- **Brooks's law still holds:** ramp-up, communication overhead and indivisible work make late additions slow a project down.
- **Agents skip the meetings, keep the rest.** Each session ramps up again from the repo and prompt, and every agent's output routes through the same human reviewers.
- **Review is the new bottleneck.** High-AI-adoption teams merged 98% more PRs while review time grew 91%.

On a late project:

1. Cut scope first and ship the smaller version.
2. Add agents at the start of a project or not at all.
3. Give each agent its own files and an acceptance test written before it starts.
4. Cap open agent PRs per reviewer.
5. Protect senior engineers' focus time.
