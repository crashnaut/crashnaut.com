---
title: "How to Be a -10x Engineering Manager When Code Is Cheap"
slug: how-to-be-a-minus-10x-engineering-manager
---

- **Agents inflate output metrics.** High-AI-adoption teams merged 98% more PRs but completed 21% more tasks; review time grew 91%; AI adoption also came with 9% more bugs per developer.
- **The -10x moves:** report PR count, cut QA because AI writes tests, add agents to late projects, ignore the review queue, measure tool usage.

To be +1x:

1. Track DORA's five metrics: change lead time, deployment frequency, failed deployment recovery time, change fail rate, deployment rework rate.
2. Budget review time and cap open PRs per reviewer.
3. Keep QA as an independent check and bring them into grooming.
4. Cut scope on a late project before adding anything that writes code.
