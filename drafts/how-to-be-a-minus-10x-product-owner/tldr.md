---
title: "How to Be a -10x Product Owner When Code Is Cheap"
slug: how-to-be-a-minus-10x-product-owner
---

- **An agent builds exactly what the ticket says.** The effort moves from the build to the requirement and the check, both of which need domain knowledge.
- **The -10x moves:** one-line tickets, hourly pivots, shipping every idea, and letting the agent write its own acceptance criteria.

To be +1x:

1. Write acceptance criteria with concrete examples (amounts, currencies, dates, roles).
2. List what's out of scope.
3. Approve the criteria and the acceptance test before the build starts.
4. Say no more often: every feature is cheap to write and expensive to own.
5. Check the result against the criteria yourself.
