# crashnaut.com

Mike Sell's site and blog: test automation, CI/CD and FinTech testing.
SvelteKit, prerendered to static HTML and served by Firebase Hosting.

## Develop

```bash
npm ci
npm run dev          # http://localhost:5173
```

## Write a post

```bash
npm run g "How to Test Idempotency in Payment APIs"   # scaffolds drafts/<slug>/index.md + tldr.md
```

Every slot from `docs/EDITORIAL-PLAYBOOK.md` §2 is stubbed as a `TODO(write)` comment;
`npm run lint:posts` fails on any that reach `blog/`.

Drafts live in `drafts/` and are never built. To publish, move the folder to
`blog/`, then run `npm run og` to render its share card into `static/og/`
(commit the PNG). Frontmatter:

```yaml
title: How to Test Idempotency in Payment APIs
slug: how-to-test-idempotency-in-payment-apis
description: One sentence, 160 characters max. Shows in search results and link previews.
date: 2026-10-15
updated: 2026-11-02 # optional; only set it when the content really changed
tags: Payments, Playwright, API Testing
```

Markdown extras: `:::tip|note|warning|danger|success`, `:::compare` with
`::do[...]` / `::dont[...]`, `:::code` tab groups, `:::bar` charts.

## Test

```bash
npm run lint:posts          # fit check: description, tags, slug, share card, TODO(, internal links
npm run test:unit           # vitest: src/**/*.test.ts (post signals, sigil, map layout)
npm run build && npm test   # Playwright against the production build, incl. axe checks
```

If you change the sigil maths in `src/lib/post-signals.ts`, run
`npm run og -- --force` and commit the regenerated cards in `static/og/`.

## Deploy

GitHub Actions (`.github/workflows/ci.yml`) checks, lints, builds and tests every
push. With the secrets below in place it deploys a Firebase preview channel for
each PR and goes live on `main`.

| Kind     | Name                       | Value                                                   |
| -------- | -------------------------- | ------------------------------------------------------- |
| Variable | `GA_MEASUREMENT_ID`        | GA4 measurement ID, e.g. `G-XXXXXXXXXX`                 |
| Secret   | `FIREBASE_SERVICE_ACCOUNT` | JSON key from `firebase init hosting:github` or GCP IAM |

Manual deploy: `npm run build && npx firebase deploy --only hosting`
(set `VITE_PUBLIC_GA_TRACKING_ID` in your shell first or analytics is left out).

## Brand

Crash-test mark (`src/lib/brand/Mark.svelte`, `static/favicon.svg`), signal yellow
`#f8c400` on ink, hazard stripes, mono "telemetry" labels. Archivo (display),
IBM Plex Sans (text), IBM Plex Mono (code), all self-hosted via Fontsource.
Share cards and favicons are generated by `scripts/og.mjs`.
