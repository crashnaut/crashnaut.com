### What to write next (in order)

The site adds the `/contact` CTA and related posts to every post. Each post still needs
2–3 hand-picked internal links in its "Related" line.

1. **How to Test Idempotency in Payment APIs: Retries, Duplicate Webhooks and
   Idempotency Keys.** Playwright `APIRequestContext` + Stripe test mode: replay the same
   key, concurrent duplicates, retry after timeout, then assert one charge and one ledger
   row. The most FinTech-specific bug class there is.
2. **Never Use Floats for Money: Testing Rounding, Currency Precision and Minor Units.**
   Property-based tests with fast-check: JPY has 0 decimals, KWD has 3, banker's rounding,
   splitting $10 three ways. Link to AI Code Smells, since AI writes `parseFloat` on amounts.
3. **Testing Stripe Webhooks in CI: Stripe CLI, Signed Payloads and Test Clocks**, with a
   GitHub Actions job. Link to cross-repo CI, ephemeral previews and mocking.
4. **Testing Time in FinTech: Cutoffs, Business Days, Time Zones and DST.** Playwright
   `page.clock`, ACH/wire cutoffs, settlement dates, DST boundaries. Link to feature flags
   (another matrix explosion).
5. **Ledger Reconciliation Testing: Proving Your Double-Entry Books Balance.** Invariants
   (debits = credits, balance = sum of entries) and a nightly reconciliation job as a test.
6. **Run Playwright in Docker Against Your Local App**: finish that draft; it's
   top-of-funnel traffic.
7. **Test Data for FinTech: Factories, Stripe/Plaid Test Credentials and Keeping PCI Data
   Out of Staging**: finish the data-factory draft. Production copies in staging pull the
   environment into PCI DSS 4.0 scope.
8. **Contract Testing Payment Integrations with Pact**: consumer-driven contracts for the
   PSP adapter and ledger service, run in CI.
