# crashnaut.com audit: October 2026

The full audit of the site's code, UI/UX and content, done on 8–9 Oct 2026 against
`origin/main` and the live site. Each item is marked:

- ✅ fixed in PR #3 (`feat/crashnaut-identity`)
- ⬜ still to do
- 👤 needs you (an account, a decision or your real experience). These are also
  listed in [`MIKE-TODO.md`](../MIKE-TODO.md).

**Short version:** you couldn't tell whether anyone was visiting, because analytics
had never run in production. The site still carried the forked template's IDs and
assets. The blog sells FinTech testing but had no FinTech posts. Eight drafts were
70–90% done, so shipping is the bottleneck, not writing.

---

## 1. Traffic: "nobody visits" was unmeasured, not measured

- ✅ **Google Analytics never ran in production.** `VITE_PUBLIC_GA_TRACKING_ID` was never
  set: there was no `.env`, and CI had no env vars and no deploy step. Vite replaced the
  missing value with `undefined` and dropped the gtag code. The live RSS feed even printed
  `webfeeds:analytics id="undefined"`. The footer showed `local` instead of a commit hash,
  which confirms production was built with no env at all. The code is fixed; CI now passes
  `GA_MEASUREMENT_ID` and warns when it's missing.
- ✅ The first page load sent two page views (`gtag('config')` and `afterNavigate`). Now
  there's one.
- 👤 Create the GA4 property, add the `GA_MEASUREMENT_ID` repo variable, and filter out
  your own visits.
- 👤 Verify the site in Google Search Console and submit the sitemap. It shows which
  queries surface your posts, with no code changes needed.

## 2. Code

### Critical / high

- ✅ **8 of 9 posts pointed `og:image` at a banner that 404'd**, so LinkedIn shares had no
  picture. Cause: the `prepare` script pointed git at a `.githooks/` folder that didn't exist,
  so `scripts/banners.js` never ran. Now `scripts/og.mjs` renders branded cards into
  `static/og/`, there's a fallback card, and a test checks that every page's og:image returns 200.
- ✅ **The giscus comments used Tim Deschryver's repository.** The repo-id
  `MDEwOlJlcG9zaXRvcnkxNzg3MjYyMDg=` decodes to `timdeschryver/timdeschryver.dev`, and the
  category ID was his too. Now it uses `R_kgDOP3-hMA` / `DIC_kwDOP3-hMM4CwkPy` with pathname mapping.
- ✅ **The Carbon Ads serve ID `CW7DV237` was Tim's**, and it was injected on every post.
  Removed.
- ✅ The `/support` redirect pointed to a PayPal donate button that wasn't yours. Removed.
- ✅ `static/images/mike.webp` was a screenshot of Tim's homepage ("Hi, I'm Tim"), and it
  was used as the author avatar. It's regenerated from `mike.jpg`.

### Medium

- ✅ The RSS feed built the post content but never output it. `lastBuildDate` used ISO
  instead of RFC 822, and links were site-relative. The feed now has `content:encoded`, RFC
  822 dates, absolute links, categories and a CTA.
- ✅ No CI deploy and no preview channels. Now there's a Firebase preview per PR and a live
  deploy on `main`. It's skipped until the `FIREBASE_SERVICE_ACCOUNT` secret exists 👤.
- ✅ Blog search passed raw input to `new RegExp()`, so typing `(` or `c++` threw. It now
  uses plain substring matching, with `?q=` and `?tag=` in the URL.
- ✅ Fonts were loaded through a render-blocking CSS `@import`, including the full Material
  Symbols variable font for about six icons. Fonts are now self-hosted via Fontsource
  (Archivo, IBM Plex Sans/Mono) and the icons are inline SVG and text badges.
- ✅ About 7.7 MB of template content shipped with the site: `static/bits`, `static/blog`
  (Angular/Moq posts), and the Tim, Angular, NgRx, .NET, RxJS, Azure and Zod images.
  All deleted, along with the template's Angular redirects in `firebase.json`.
- ✅ `getLastModifiedDate` ran `git log` per post with no error handling. A shallow CI
  clone gave every post the same date, and a bulk reformat made every post say "Modified
  20 June 2026". Now only an explicit `updated:` frontmatter field counts.
- ✅ Dates rendered a day early: UTC midnight was formatted in the reader's local time zone
  (22 Apr instead of 23 Apr in Brazil and the US). They're now formatted in UTC.

### Low

- ✅ Dead template code removed: the tweet preview, beehiiv newsletter IDs, translations,
  NgRx and .NET tag colours, Angular/Razor/C# Shiki languages, `twitterBearerToken`,
  `devto.js`, `contributors.js`, the indieweb favicon-on-link feature, and `canvas-confetti`.
- ✅ The Ko-fi widget only drew if the async script beat `onMount`, and it loaded on every
  post. Removed. The site now asks readers to hire you, not tip you.
- ✅ Svelte 5 patterns: the TOC, headings and pre queries ran inside `$derived` (one-off,
  non-reactive). The blog page `$effect` called `goto` on every keystroke. Both rewritten
  (scroll-tracked TOC, `replaceState` in event handlers).
- ✅ YAML array `tags:` were silently wiped (only comma strings were parsed). Both forms now work.
- ✅ The error page called every error "Page not found" and set the canonical to the
  homepage. Now it shows the real status, has no canonical, and is `noindex`.
- ✅ The sitemap `lastmod` for `/` and `/contact` changed on every build. It now follows
  the newest post.
- ✅ Tests were 10 HTML-string checks. Now there are 26 Playwright tests:
  - request-level checks of the sitemap, titles, canonicals, og:images, internal links,
    template leftovers, RSS and dates
  - browser tests of search, tags, TL;DR, the CTA, 404 and mobile overflow
  - axe checks in light and dark themes
    The axe checks caught low-contrast status colours, which are now fixed.
- ✅ Dependencies: Playwright 1.48 → 1.64 (and the duplicate `playwright` pin removed),
  `axe-playwright` → `@axe-core/playwright`, `@squoosh/lib` (abandoned) → `sharp`. Removed
  `@types/marked`, jsdom, testing-library, dotenv-extended, node-fetch and lint-staged.
- ⬜ Upgrade SvelteKit 2.25 → current, Vite 5 → current, vite-plugin-svelte, vitest, marked
  and shiki, as their own PR.
- ⬜ Turn on `"strict": true` in `tsconfig.json`.

### Already right before the audit

Canonical URLs, Firebase `cleanUrls`/`trailingSlash: false` (`/x/` → 301 `/x`), real 404s,
`robots.txt` with the sitemap, and Person/WebSite/BlogPosting/Breadcrumb JSON-LD.

## 3. UI / UX / visuals

- ✅ **Post pages opened on an empty, full-viewport hero**, worst on mobile: readers saw
  only the title until they scrolled. Now there's a compact header (crumbs, title,
  description as a deck, byline, date, reading time, tags) and the first paragraph is
  visible straight away.
- ✅ "Modified 20 June 2026" on every post hid the publish date. Now the publish date shows,
  plus "updated" only when it's real.
- ✅ The post title showed through the translucent header and there were two `<h1>`s per
  post. Now there's one `<h1>`, and a duplicate leading H1 in the markdown is stripped.
- ✅ **The homepage had no proof:** a skills list and a Calendly button. Now it has a claim
  headline, a test-report hero, three "suites" (services), recent posts and a CTA.
- 👤 Real proof is still missing: a case study, numbers, testimonials or logos.
- ✅ Posts ended with "Support me" (Ko-fi) instead of an offer. Every post now ends with a
  "Want this kind of rigor on your team?" block (Calendly + Work with me), then related
  posts, share links (LinkedIn, Bluesky, copy link), a "Suggest an edit" link and comments.
- ✅ **It still looked like Tim's template.** New identity, "crash test lab":
  - logo: crash-test target mark, also used for the favicons
  - colour: signal yellow `#f8c400` on ink, with hazard stripes
  - details: mono "telemetry" labels, posts numbered as "Run 00N", PASS/FAIL/WARN callout
    badges, and a custom syntax theme with yellow keywords
  - pages: the blog index is now "The crash log", contact is now "Work with me", and the
    404 page is a failed test
- ✅ Only LinkedIn sharing, with no image. Share cards are now generated for every post.
- ✅ Bluesky share and redirect removed (no account), along with the `/twitter` redirect.

### What to write next (in order)

Each post should end with a link to `/contact`, which the template now does for you, and
link to 2–3 related posts.

1. **Ship drafts 2–5 above** as the "integration tests that catch real bugs" series.
2. **How to Test Idempotency in Payment APIs: Retries, Duplicate Webhooks and
   Idempotency Keys.** Playwright `APIRequestContext` + Stripe test mode: replay the same
   key, concurrent duplicates, retry after timeout → assert one charge and one ledger row.
   The most FinTech-specific bug class there is.
3. **Never Use Floats for Money: Testing Rounding, Currency Precision and Minor Units.**
   Property-based tests with fast-check: JPY has 0 decimals, KWD has 3, banker's rounding,
   splitting $10 three ways. Link to AI Code Smells, since AI writes `parseFloat` on amounts.
4. **Testing Stripe Webhooks in CI: Stripe CLI, Signed Payloads and Test Clocks**, with a
   GitHub Actions job. Link to cross-repo CI, ephemeral previews and mocking.

   `page.clock`, ACH/wire cutoffs, settlement dates, DST boundaries. Link to feature flags

6. **Ledger Reconciliation Testing: Proving Your Double-Entry Books Balance.** Invariants
   (debits = credits, balance = sum of entries) and a nightly reconciliation job as a test.
